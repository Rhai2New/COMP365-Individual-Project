ROOT CAUSE:
The code uses the comparison operator `==` instead of the assignment operator `=` to assign a value to `total`.

BEGINNER EXPLANATION:
In Java, `=` and `==` do two different things:
- `=` is the assignment operator, used to store a value into a variable (for example, `int total = 7;`).
- `==` is a comparison operator, used to check if two values are equal (for example, `if (total == 7)`).

Because this line is declaring and initializing a variable, it needs a single `=` instead of `==`.
